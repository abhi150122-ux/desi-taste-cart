# Desi Harvest Hub

Build a Complete Quick-Commerce Grocery Website — Jain Desi and Pure

Brand Name: Jain Desi and Pure

The website should have a modern quick-commerce experience inspired by websites/apps like Blinkit and Zepto — fast product discovery, horizontal category sliders, prominent hero banners, product cards, cart drawer/page, checkout, login/signup, search, etc.

Do NOT copy Blinkit's branding, logo, colors, text, images, or exact UI. Create an original design with a similar quick-commerce shopping experience.

The supplied product list contains duplicate products, inconsistent capitalization, typos and some garbage/test values such as:

dfgdshrtfjh

jhtyuityityui

htryhrtyhtyheryheryh

dgrfyteryhtrytr

Ignore these garbage/test entries.

Normalize product names and units.

Examples:

should display as:

Cold Pressed Groundnut Oil — 900 ML

MAKHANA 250 Gm

should display as:

Makhana — 250 Gm

SONAMANSOORI CHAWAL 500 gram

should display as:

Sonamasuri Chawal — 500 Gm

Maintain consistent capitalization throughout the website.
